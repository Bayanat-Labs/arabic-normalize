# raw-safe-v1

**تنظيف آمن دون تغيير الحروف، الإصدار 1**

| الحقل | القيمة |
|---|---|
| معرّف السياسة | `raw-safe-v1` |
| بصمة SHA-256 | `57c3d9f03fb9b6854f2527cd1e8a47cadc266f47f02dda94652306dacea03bb5` |
| المواصفة | arabic-normalize-spec-1 |
| يونيكود | 18.0.0، صيغة NFC |
| ثبات الناتج عند إعادة التطبيق | نعم (مختبَر) |

| الترخيص | CC BY 4.0 لملف السياسة، بيانات لابز |

## الاستخدام

تنظيف لا يغيّر أي حرف أو علامة أو رقم أو علامة ترقيم. وهي الوصفة المعتمدة لحقل النص المشكول text_diac، وتناسب العرض والنصوص القانونية.

## القواعد الفاقدة للمعلومات

لا توجد؛ فلا يتغير أي حرف.

يُسجَّل كل تغيير فاقد للمعلومات في سجل التغييرات مع `lossy: true`، ويظهر في قائمة `lossy_flags`.

## القيود

- تحذف هذه السياسة محارف التحكم الاتجاهي، وقد يغيّر ذلك طريقة عرض النص الذي يجمع الكتابة من اليمين إلى اليسار ومن اليسار إلى اليمين؛ احتفظ بالنص الخام إذا كانت دقة العرض مهمة.
- تُبقي هذه السياسة أشكال العرض والتطويل والحركات وجميع الحروف.
